Typography

Product-wide stack: Satoshi (display / headlines) + Inter (UI, body, buttons).

Product display — Fraunces
Building clarity, project by project
Product body — DM Sans
Use DM Sans for UI labels, forms, body copy, and buttons. Weight 400–700. Headings use letter-spacing −0.02em and line-height ~1.55–1.6 for body.
Landing display — Playfair Display
Survey-ready marketplace
Landing elegant — Cormorant Garamond
Precision with a human touch
Landing body — Inter
Inter carries marketing body copy at 16px / 1.6 for readable long-form content.

Usage guidance

  • Brand color is purple (#7168F6) — use it for accents, CTAs, active states, and marketing.
  • Do not use the old navy / sky / ice blue system for new brand or product UI.
  • Keep canvases light (#F7F8FF / white); let purple carry emphasis.
  • Product headlines → Fraunces; product UI → DM Sans.
  • Landing → Playfair / Cormorant / Inter.
  • Prefer CSS variables from globals.css / landing.css over hard-coded hex when shipping UI.
